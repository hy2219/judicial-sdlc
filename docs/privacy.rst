개발용 가상 자료와 실제 PDF의 로컬 처리
=======================================

비공개 저장소와 복사본에도 같은 자료 제한을 적용합니다.
비공개는 실자료 업로드 허가가 아닙니다. 저장소 공개 전환은 별도 승인 대상입니다.

외부 업로드 금지 대상
--------------------

실제 재판 PDF, 실물 문서를 스캔한 이미지, 실제 사건의 내용이나 개인정보,
익명화·가명화한 실제 자료도 GitHub·Agent·Actions로 보내지 않습니다.
실제 문서를 복사한 뒤 이름만 바꾸는 것은 합성 데이터 생성이 아닙니다.
개발과 CI에서는 처음부터 만들어 낸 가상 텍스트와 fixture만 사용합니다.
설치 앱은 사용자와 기관이 허가한 실제 PDF를 해당 PC에서 읽을 수 있습니다.
파일의 합성 표시는 필수 조건이 아니며 입력이나 결과의 업로드 기능은 없습니다.
실제 문서로 하는 확인은 외부 Agent 작업과 분리하고 원문을 로그에 남기지 않습니다.

Git 파일뿐 아니라 Issue, PR, 댓글, 첨부, Actions 로그, Agent 대화에도
이 정책이 적용됩니다. 실제 이메일 주소, 내부 URL, 계정, 비밀번호, API 키,
서명키를 공유하지 마세요. 메일 발송 기능은 이 최소 템플릿에 포함하지 않습니다.
PDF는 합성이어도 저장소에 보관하지 않으며 로컬 명령으로 생성합니다.

오프라인 OCR의 경계
--------------------

CRAFT 검출과 KLOCR 인식은 한국어/영어를 CPU에서 처리합니다. 실제 자료는 허가된 PC 안에서만
처리하고 기관의 사용·보존 정책을 따릅니다. 모델과 라이선스는 ``modules/ocr/prepare.py``로 빌드/준비 시에만
다운로드하고 고정 해시를 검증합니다. ``assets/klocr/``와 모델 가중치·아카이브는
생성물이며 Git에 보관하지 않습니다. 설치파일에는 필요한 라이브러리와 모델, 고지를
포함하되 공개 콘텐츠 검사를 우회하여 바이너리를 소스에 커밋하지 않습니다.
KLOCR 가중치의 CC-BY-NC-SA-4.0 조건은 비상업·동일조건변경허락 제한을 포함하므로
기관 사용과 재배포 권한을 별도로 확인해야 합니다. 코드 라이선스와 혼동하지 마세요.

런타임은 GPU와 모델 다운로드를 끄고 번들/로컬 검증 경로만 사용합니다.
환경 변수로 임의 모델 디렉터리를 선택하거나 네트워크 공유 경로를 통해 입력을
가져오는 우회 기능을 추가하지 않습니다. 판례/SLM 서비스는 여전히 loopback의
가상 데이터와 고정 응답뿐입니다. OCR 인식이 틀릴 수 있으므로 사람이 확인하며
인식 결과도 자동 업로드하지 않습니다.
일반 PDF의 최대 크기/쪽수는 50MB/100쪽입니다. 암호화·주석/양식 등 지원하지 않는
구성은 오류로 알리고 빈 결과를 성공처럼 반환하지 않습니다.
개발자가 합성 자료 전용 시험을 원할 때만 read_document(..., synthetic_only=True)를 사용합니다.

터미널 없는 앱과 로컬 로그
---------------------------

배포 앱은 별도 콘솔 없이 동작하고 Python 오류를 팝업으로 안내합니다.
modules/diagnostics.py는 사용자별 로컬 폴더에 시각·오류 종류·코드 위치만 기록합니다.
예외 메시지·본문·변수 값·입력 경로·원문 줄은 기록하지 않습니다. 최대 256KiB 로그와
이전 로그 하나를 보관하고 자동 전송하지 않습니다. 문서를 처리한 흔적 자체도 민감할
수 있으므로 외부 공유 전 사용자와 기관의 정책을 확인하세요.

공유 전 점검
------------

``python .github/scripts/check_public_content.py``는 현재 저장소의 Git index를 기준으로
파일 경로, staged blob 내용, 해당 추적 파일의 작업 사본을 검사합니다.
커밋 전 ``git add``만 한 새 저장소도 지원합니다. Git이 없거나 index가 비어 있으면
성공으로 가장하지 않고 실패합니다. staged blob을 수정하지 않은 채 작업 파일만
지우거나 수정해도 staging된 위험 내용은 탐지합니다.

PDF/이미지/Office 문서/아카이브/실행 파일, 입력·출력·로컬 디렉터리,
자격증명 파일, 일부 키 패턴과 사설 URL을 거부합니다. 확장자를 바꾼 PDF와
일부 바이너리 내용도 검사합니다. 경고에는 파일명과 사유만 출력합니다.
loopback mock URL과 명백한 일부 데모 상수는 허용합니다.

이 도구는 완전한 DLP, 비밀 탐지기, 바이러스 검사기가 아닙니다.
일반 텍스트에 쓴 실제 사건 내용, 인코딩/난독화 데이터, 모든 자격증명 형태를
탐지하지 못합니다. 오탐도 가능합니다. 검사 통과는 공개 허가가 아닙니다.
Git 이력 전체, untracked 파일, GitHub 댓글/첨부/로그를 검사하지 않습니다.
``.gitignore``와 양식 확인란도 실제 정보의 공개를 방지하는 보안 경계가 아닙니다.
사람이 diff와 공개할 내용을 확인하고 기술 승인자가 최종 검토해야 합니다.

이미 공개한 경우
----------------

CI 실패는 이전 업로드를 취소하지 않습니다. 추가 공유를 중단하고 기관의 보안/
개인정보 담당 절차에 따라 대응하세요. 노출된 자격증명은 폐기·교체하고,
공개 Git 이력, 캐시, 첨부와 로그의 정리는 관리자와 별도로 검토합니다.
Issue에 원본을 다시 붙여 사고를 설명하지 마세요.
